# Shortcut keys
| shortcut key | purpose | remark |
| :---: | :---: | :---: |
| cmd + opt + d | hidden Dock | / |
| ctrl + e | home | move cursor to the beginning of the line |
| ctrl + a | end | move cursor to the ending of the line |
| home / end / pgup / pgdn | home / end / pgup / pgdn | must use in vscode |
| ctrl + scroll | full screen zoom in / out | must [set](https://juejin.cn/post/7235718907839152165) in setting |
